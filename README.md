# NyanDex — site inicial

Primeira estrutura estática do site NyanDex, feita com HTML, CSS e JavaScript puro para compatibilidade com Cloudflare Pages.

## Arquivos
- `index.html` — estrutura da página
- `styles.css` — identidade visual retrô responsiva
- `script.js` — pequenos comportamentos do site
- `assets/nyan-cat.svg` — mascote pixel art provisório

## Publicar na Cloudflare Pages
Use o diretório raiz do projeto. Como não há etapa de build, deixe o comando de build vazio e o diretório de saída como `/` (raiz).

Este é apenas o primeiro esqueleto visual; autenticação, repositórios, banco de dados e os módulos do ecossistema ainda não foram implementados.
